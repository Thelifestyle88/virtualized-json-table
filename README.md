# Каталог товаров

## Запуск

Локально с Node.js 22.12 или новее

```sh
npm ci
npm run dev
```

В Docker

```sh
docker compose up --build
```

Приложение откроется по адресу [http://localhost:5173](http://localhost:5173).

## Архитектурные решения

- **Данные.** Vite в режиме разработки отдаёт файл `public/data/products.json` с 5 000 тестовых записей порциями и с заголовком `Content-Length`. Процент считается по полученным байтам, а отмену можно проверить на локальном соединении.
- **Граница API.** Транспорт `downloadJson` отвечает за HTTP, прогресс и отмену через `AbortSignal`. Адаптер `loadProducts` проверяет структуру ответа и уникальность идентификаторов. Таблица получает типизированные данные через props.
- **Состояние загрузки.** `useProductsDownload` управляет запросом, а типизированный reducer описывает переходы между состояниями. Идентификатор запроса позволяет игнорировать запоздавшие события после отмены и повторной загрузки.
- **Таблица и поиск.** После паузы в 300 мс TanStack Table фильтрует весь набор на клиенте. Фильтрация и подсветка используют одинаковые правила буквального поиска без учёта регистра. TanStack Virtual отрисовывает только видимые строки с запасом. При росте объёма данных загрузку и фильтрацию можно перенести на сервер, сохранив отрисовку виртуальных строк.
